# Recruiter Role

The Recruiter role is a repo-safe, read-only role package skeleton.

Its MVP purpose is to:

- evaluate a vacancy with machine score context when available;
- produce a recruiter positioning packet with evidence and gaps;
- produce draft only application materials for user review;
- review those drafts for unsupported claims, weak evidence, and generic writing.

The role does not enable live routing in this slice and does not perform provider calls, Telegram smokes, or outbound actions.
